# Aplicação React de Login

Aplicação desenvolvida em React de tela de login

O sistema apresenta um formulário de login com campos de e-mail e senha. Ao enviar o formulário, as credenciais são verificadas e uma mensagem de sucesso ou erro é exibida ao usuário.

## Funcionalidades

- Campo de e-mail
- Campo de senha
- Validação das credenciais
- Mensagem de sucesso
- Mensagem de erro
- Interface desenvolvida em React
